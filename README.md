**RAG Optimizer Pro** es la plataforma SaaS definitiva para la optimización automática de pipelines de Generación Aumentada por Recuperación (RAG). Diseñada para eliminar el tuning manual, reducir costos operativos y maximizar la precisión de las respuestas.

---

## 🏗️ Arquitectura Técnica

El sistema sigue el estándar **AI Engineer 2026** centrado en resultados inmediatos y eficiencia de tokens.

### Stack Tecnológico
- **Frontend:** React 19, Vite 7.2, Tailwind CSS 4 (Atomic Architecture).
- **Backend (Planned):** Python 3.12, Flask, Socket.IO, MCP-Python-SDK.
- **Persistence:** Supabase (PostgreSQL) + Redis (Hybrid Memory).
- **Vector Engine:** RedisVL + Pinecone (High-Fidelity RAG).

### Flujo de Optimización
1. **Auto-Embedding:** Clasificación dinámica de datos y selección de modelos (CNN + RL).
2. **Adaptive Chunking:** Segmentación inteligente basada en patrones de acceso al dominio.
3. **Semantic Caching:** Reducción de hasta el 60% en costos de LLM mediante hit rate predictivo.
4. **Auto-Reranking:** Fine-tuning de re-ordenamiento en tiempo real.

## 🚀 Inicio Rápido

### Requisitos Previos
- Node.js v20+
- Bun (Recomendado para instalaciones rápidas)
- Docker (Para el entorno de backend)

### Instalación del Frontend
```bash
cd rag-pipeline-optimizacin-saas
npm install
npm run dev
```

### Estructura del Proyecto
```text
rag-pipeline-optimizacin-saas/
├── src/
│   ├── components/     # UI Atómica y Moléculas
│   ├── pages/          # Vistas maestras (Home, Producto, Docs, etc.)
│   ├── utils/          # Utilidades (Tailwind merge, cn)
│   └── App.tsx         # Router y configuración global
├── backend/            # Lógica de IA y MCP Servers (Vacío)
└── README.md           # Este archivo
```
